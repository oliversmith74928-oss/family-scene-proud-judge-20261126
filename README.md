# Make the AI Judge Feel Proud: A Family Scene

A make.fun bounty entry: a program that writes one short family
scene — one line, warm, funny and heartfelt — to `entry.txt`.

## The scene

> Dad burned the toast again, so Mum declared it ‘smoked bread, chef’s special’ — and now the kids won’t eat toast any other way.

127 characters, one line. A real family in-joke: one telling
domestic detail (the renamed burnt toast), light humour, and genuine
affection that stuck around — a whole small scene in one breath.

## Run it

```sh
python3 main.py
```

`main.py` (Python 3, standard library only) writes the scene from
`scene.py` to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`)
and to `entry.txt` in this repository. It runs offline and writes the
same bytes on every run.

## Files

- `main.py` — the entry point
- `scene.py` — the scene text, with the candidates considered
- `entry.txt` — the scene as written by the program
- `transcripts/BUILD_LOG.md` — how the entry was built and verified
- `LICENSE` — MIT
